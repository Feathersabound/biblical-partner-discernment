# Biblical Partner Discernment

Browser app that walks one incident through Scripture-based discernment.

Open `index.html` in a browser. No server required.

GitHub Pages: enable Pages on this repo (Settings → Pages → Deploy from branch `main`).

## What it does

1. Names marriage vs dating
2. Separates fact from interpretation
3. Names the belief
4. Tests it (partner, Scripture, Spirit vs self)
5. Names the speech
6. Names trigger histories (rejection, abuse, parenting, divorce, false teaching)
7. Names spiritual issues
8. Checks surrender — individual and together
9. Flags possible traits without diagnosing
10. Frames reaction with 1 Corinthians 13 (makrothymei, paroxunetai, logizetai)

## Doctrine held

- Scripture is primary
- Marriage is covenant; dating is not
- Wife obeys her husband as unto the Lord, not because he is better
- Husband must not abuse or command sin
- Constructive criticism from both is useful when fact-first
- Triggers explain intensity; they do not prove the premise
- Derek Prince used where it matches Scripture: words, testing, deliverance

This is not a clinical tool and not a substitute for the church or qualified care.
